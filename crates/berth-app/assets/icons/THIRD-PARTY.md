# Third-party icons

Every icon here is a single-colour SVG, drawn in the text colour of the theme.
None is shown in a brand's own colours.

## Trademarks

The licences above cover the drawings, not the marks. The Claude and Codex
marks belong to Anthropic and OpenAI, and the marks from Simple Icons to
their projects and companies. In Berth they say which program runs in a tab
and nothing else.

**They are for dogfooding only.** Before any release: written permission from
Anthropic and from OpenAI for their marks, and a review of each other
project's brand policy. Any mark that cannot be cleared is replaced by
Phosphor's generic terminal icon, which is what an unknown program gets
already. This is a release blocker, listed in the macOS runbook beside the
app's own logo.
